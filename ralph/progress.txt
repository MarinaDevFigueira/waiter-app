## Codebase Patterns
- Use array + `.includes()` pattern for multi-role checks instead of chaining `===` with `||`
- Always extract boolean conditions into named variables before `if` statements
- UserProfileEnum values: OWNER, ADMIN, ATTENDANT, COZINHA, MESA, DELIVERY
- Cast profile to `UserProfileEnum` when using `.includes()`: `dashboardProfiles.includes(profile as UserProfileEnum)`
- Test helper `loginAsAdmin` logs in as `iconsagrado` which is OWNER profile, not ADMIN
- E2E tests use Playwright (`npx playwright test`), NOT Vitest
- Variable naming: use intention-based names (hasFullMenuAccess, hasOrdersAdminAccess) not implementation-based (isAdmin)
