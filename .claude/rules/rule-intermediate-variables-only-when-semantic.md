Use intermediate variables only when the name adds semantic meaning. USAR quando: expressão envolve múltiplas operações, nome adiciona contexto, cache de operação lenta, facilitar debug. NÃO USAR quando: nome repete o nome da função, propriedade já é contextualmente clara, ou o cálculo intermediário não faz sentido semântico. Regra de ouro: Se não consegue nomear a variável de forma significativa, ela não deveria existir.
