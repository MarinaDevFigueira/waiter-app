## Component Misc
- Buttons: `hover:cursor-pointer` + `active:shadow-*` or `active:scale-95`.
- Non-interactive elements: `text-muted-foreground select-none`.
- Pages: `w-screen h-screen` outer → `max-w-7xl max-h-[720px] flex items-center justify-center` inner.
- Use `w-screen` on router components, `w-full` on nested.
